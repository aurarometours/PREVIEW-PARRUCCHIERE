# LineRudy Hairstyle — sito React/Vite

## Avvio locale
```bash
npm install
npm run dev
```

## Build produzione
```bash
npm run build
```

## Video hero
Metti il video definitivo qui:

```txt
public/videos/linerudy-hero-hair-atelier.mp4
```

Se il video non è presente o non carica, il sito mostra automaticamente una fallback image coerente.

## Deploy GitHub Pages
Consigliato con Vercel/Netlify per Vite. Su GitHub Pages puoi usare una GitHub Action o buildare `dist/` e pubblicarla.
